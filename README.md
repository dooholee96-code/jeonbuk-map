# 전북 학교 통합지도

전북특별자치도 14개 시군의 **유치원·초·중·고·특수학교**를 지도 하나로 봅니다.
기본 화면은 전북 전체이고, 선택창에서 시·군을 고르면 그 지역만 봅니다.

기본은 **전체**입니다 — 유치원·초·중·고·특수학교가 다 들어 있습니다.
맨 위 **지도 종류** 선택창으로 한 가지에 집중한 화면으로 바꿀 수 있고,
주소에 `?map=` 을 붙이면 바로 열립니다.

| 지도 | `?map=` | 담긴 것 |
|---|---|---|
| **전체** (기본) | `all` | 1,126곳 — 유치원 373 · 초 404 · 중 206 · 고 132 · 특수학교 11. 농촌유학·특수학급 표시도 함께 |
| **농촌유학** | `rural` | 초·중·고 742교 + 2026-2학기 농촌유학 운영 48 · 희망 11 |
| **특수교육** | `special` | 특수학교 11교 + 특수학급을 둔 유치원·초·중·고 502곳 (641학급 · 2,727명) |
| **유치원** | `kinder` | 유치원 453원 (단설 36 · 병설 307 · 사립 110), 휴원 80원 포함 |

**전체**는 나머지 셋의 상위 집합이라 농촌유학 지정(★☆)과 특수학급 표시가 그대로 살아 있습니다.
집중 화면은 필요한 것만 남겨 보려고 두는 것이지, 거기에만 있는 데이터는 없습니다.
(휴원 유치원 80원은 어느 화면이든 기본에서 빠지고, [형태]에서 `휴원` 을 골라야 보입니다.)

네 지도는 **같은 지도 엔진 한 벌**을 공유합니다. 브랜치를 나누지 않은 이유이기도 합니다 —
경계·라벨·바텀시트·편집 코드를 고치면 네 지도에 한 번에 반영됩니다. 갈라지는 것은
`config.js` 의 `JB.MAPS` 안, 어떤 데이터를 어떤 색·범례·요약으로 보여 줄지뿐입니다.

**코드에 API 키를 넣지 않습니다.** 지도는 Leaflet + OpenStreetMap 을 쓰고 Leaflet 은 저장소에
동봉돼 있어, 정적 호스팅에 파일만 올리면 그대로 뜹니다. 인수인계할 때 계정이나 키를 넘길 게 없습니다.

```
├── index.html
├── assets/
│   ├── vendor/leaflet/         Leaflet 1.9.4 (BSD-2, 동봉 — CDN 불필요)
│   ├── css/app.css
│   ├── js/
│   │   ├── config.js           타일 설정, 14개 시군, 학교급 분류, 지도 종류(JB.MAPS)
│   │   ├── labels.js           라벨 자동배치 엔진 (겹침 회피 + 지시선)
│   │   ├── edit.js             편집 모드 (폼·검증·내보내기)
│   │   └── app.js              메인
│   └── data/
│       ├── boundaries.js       14개 시군 경계 (16KB)
│       └── eupmyeon.js         읍·면·동 중심 좌표
└── data/                       ★ 데이터 — 여기만 고치면 됩니다
    ├── regions/                초·중·고 (14개 시군)
    ├── kinder/                 유치원 (14개 시군)
    └── special/                특수학교 (7개 시군 — 특수학교가 있는 곳만)
```

`regions/` 는 `JB.registerRegion(시군, …)`, `kinder/` 와 `special/` 은
`JB.registerSet('kinder'|'special', 시군, …)` 로 등록합니다. 파일 형식은 같습니다.

## 화면

- **지도 종류 선택창** — 전체 / 농촌유학 / 특수교육 / 유치원. 고른 값은 그 브라우저에 저장됩니다.
- **지역 선택창** — 기본 `= 전북 전체 =`, 시부/군부로 묶인 14개 시군.
  시군을 고르면 바깥이 흐려지고 그 지역만 또렷하게 남습니다.
- **형태 선택창** — 지도 종류마다 항목이 달라집니다.
  전체는 학교급·특수학교·농촌유학·특수학급 설치교·휴원 유치원을 다 고를 수 있고,
  농촌유학은 초/중/고·운영·희망, 특수교육은 특수학교/특수학급 설치교/학교급별,
  유치원은 단설·병설·사립·특수학급 운영·휴원.
- **검색** — 학교명·읍면동·주소
- **총 N교 / 학생 N명** — 현재 필터 기준 실시간 집계
- **카드 목록** — 학교급·농촌유학 태그, 주소, 전화, 학생수·학급수.
  클릭하면 지도가 그 학교로 이동하고 해당 마커가 강조됩니다.
  전북 전체에서는 시군별로, 시군을 고르면 읍·면·동별로 묶입니다.
- **라벨** — 기본 `자동`. 전북 전체에서는 그 지도의 핵심 대상만(전체·농촌유학 지도는
  농촌유학 학교와 특수학교 / 특수교육 지도는 특수학교 / 유치원 지도는 단설유치원),
  시군을 고르면 전부 표시합니다.
  줌·이동할 때마다 겹치지 않는 자리를 다시 계산하고, 자리가 없으면 라벨만 숨깁니다(확대하면 다시 나옵니다).
  선택한 학교의 라벨은 모드와 상관없이 항상 보입니다.

### 좁은 화면

목록이 지도 위로 올라오는 **바텀시트**가 됩니다. 위쪽 손잡이를 끌어 크기를 바꾸고,
톡 치면 세 단계(요약만 → 기본 → 목록 위주)를 돕니다.

- 목록에서 학교를 고르면 시트가 접히면서 지도가 크게 열립니다. 손잡이를 올리면
  보던 자리 그대로 목록으로 돌아옵니다.
- 시군을 고르거나 학교를 고를 때, 시트가 가리는 높이를 뺀 영역에 맞춰 지도가 움직입니다.
- 마커·라벨과 카드가 좁은 화면용 크기로 줄어들고, 헤더는 한 줄로 접힙니다.

점선 마커와 `좌표 추정` 표시로 구분됩니다. 같은 자리에 겹치는 원들은 작은 원형으로 흩어 놓았습니다.

### 특수학급

초·중·고 742교 중 **449교**가 특수학급을 둡니다(556학급 2,470명). 유치원은 53원 85학급 257명.
학교 기록의 `sp`(학급수) · `spStu`(학생수) 필드이고, 없으면 특수학급이 없다는 뜻입니다.

전북대사대부고·전주교대전주부설초·서전주중 세 곳은 2026 교육통계연보 학교일람표에
행이 없어 특수학급 여부를 **모릅니다**(0으로 단정하지 않았습니다).

`Ⅴ-6.특수학급` 집계표와 대조하면 고등학교는 46/46 전부 일치하고,
유·초·중은 56개 비교 중 53개가 일치합니다. 어긋나는 셋은 군산 초등(46/45학급·230/224명 —
차이가 정확히 전주교대군산부설초 1학급 6명이라 집계표가 국립을 뺀 것으로 보입니다)과
진안 초등(8/9학급)입니다.

### 출처와 가공 규칙

| 항목 | 출처 | 처리 |
|---|---|---|
| 학교명·소재지·주소·전화·학급수·학생수 | 2026학년도 전북교육청 초·중·고 현황 | 소계·합계 행 제외, 14개 시군만. 학생수는 특수학급 포함 **합계 전체** 열 |
| 위도·경도 | 2026 학교별 위치정보 | 학교명을 정규화(`초등학교→초` 등)해 매칭 |
| 농촌유학 | 희망학교·운영학교 지정 현황 | **2026-2학기 희망(P열)** 과 **운영(Q열)** 을 대조해, 두 곳에 다 있으면 **운영**, 희망에만 있으면 **희망** |
| 유치원·특수학교·특수학급 | 2026 전북교육통계연보 `Ⅶ. 학교일람표` (유치원·특수) 와 `Ⅶ-2~4` 의 특수학급 열 | 소계·합계 행 제외. 학생수는 **합계 전체** 열. 병설유치원은 원명에서 `병설` 을 떼고 초등학교와 매칭(306/307) |

농촌유학 판별: 2학기 희망 45교 ∩ 운영 48교 = 33교 중복 → 운영 48 / 희망 12.
이 중 `덕유샘학교(중)` 은 초·중·고 현황에 없는 각종학교라 **제외했습니다**.
따라서 지도에 실린 것은 **운영 48 / 희망 11**입니다.

학기를 바꾸려면 같은 파일의 1학기 열(희망 N · 운영 O)로 다시 뽑으면 됩니다.
1학기 기준은 운영 44 / 희망 16 이었습니다.

**교차검증** — 별개 자료인 `전북 농어촌 유학생 명단`(2026-08-20)에서 종료일 칸이
`유학중` 인 재학생 350명의 소속 학교를 뽑으면 48곳이 나오는데, 위 지정 현황으로
정한 운영학교 48곳과 **정확히 일치**합니다(차이 0). 손으로 만들었던 순창 지도
(운영 11 · 희망 2)와 남원 지도(운영 2 · 희망 1)와도 맞습니다.

## 데이터 고치기

### 앱 안에서 (권장)

주소 뒤에 **`?edit=1`** 을 붙이면 편집 모드가 켜집니다.
예: `https://<사이트>/?edit=1` · 끄려면 `?edit=0` 또는 막대의 [편집 끝]

- **학교 상태 변경** — 농촌유학 지도에서 학교를 고르면 상세카드에 `미지정 / 희망 / 운영` 버튼이 나옵니다. 한 번 눌러 바꿉니다.
- **정보 수정** — [정보 수정]으로 이름·학교급·읍면동·학생수·학급수·특수학급·주소·전화·좌표·메모를 고칩니다.
  좌표는 [지도에서 위치 찍기]를 누르고 지도를 클릭하면 채워집니다(찍으면 `좌표 추정` 표시가 사라집니다).
  유학 종료 같은 이력은 **메모**에 적어 두면 상세카드에 표시됩니다.
- **추가 / 삭제** — 막대의 [+ 학교 추가], 수정 폼의 [삭제].

네 지도 모두 같은 방식으로 편집합니다. 고른 대상이 어느 목록(초·중·고 / 유치원 / 특수학교)에
속하는지 앱이 알아서 판단하고, 폼 항목도 거기에 맞게 바뀝니다
(유치원은 설립 유형·휴원, 특수학교는 설립). **전체** 지도에서 새로 넣을 때만
"어느 목록에 넣을까요"를 먼저 고릅니다.

서버가 없으므로 편집 내용은 **이 브라우저에만** 쌓입니다(새로고침해도 남습니다).
확정하려면 **[내보내기]** 로 파일을 받아 저장소의 같은 경로에 덮어쓰세요.
받은 파일 이름은 `jinan.js`(초·중·고) · `kinder-jinan.js` · `special-jinan.js` 처럼 구분되지만,
저장할 때는 각각 `data/regions/jinan.js` · `data/kinder/jinan.js` · `data/special/jinan.js` 입니다
(내보내기 알림이 경로를 알려 줍니다).
GitHub 웹에서 해당 파일을 열고 연필 아이콘 → 전체 선택 후 붙여넣기 → Commit 하면 됩니다.
[되돌리기]는 브라우저에 쌓인 편집분만 지우고 저장소 파일은 건드리지 않습니다.

> 편집분을 내보내기 전에 저장소 파일이 갱신되면, 묵은 편집분이 새 데이터를 덮어쓰지
> 않도록 자동으로 건너뛰고 알려 줍니다.

### 파일을 직접

`data/regions/<시군>.js`(초·중·고) · `data/kinder/<시군>.js` · `data/special/<시군>.js`
중 한 파일만 고치면 됩니다. GitHub 웹에서 연필 아이콘으로 바로 편집해도 됩니다.

```js
{"n":"구림초등학교","t":"elem","ph":"구림면","rural":"운영",
 "lat":35.4527504,"lng":127.1009503,
 "addr":"순창군 구림면 방화로 6","tel":"063-652-8434","stu":19,"cls":6}
```

| 필드 | 뜻 |
|---|---|
| `n` `t` | 학교명 / `elem`·`mid`·`high` (필수) |
| `lat` `lng` | 좌표 (필수) |
| `ph` | 읍·면·동 — 목록 그룹 기준 |
| `rural` | `'운영'` \| `'희망'` — 없으면 일반 학교 |
| `stu` `cls` | 학생수 / 학급수 |
| `addr` `tel` | 주소 / 전화 |
| `branch` | 분교 |
| `sp` `spStu` | 특수학급 수 / 특수학급 학생수 — 없으면 특수학급 없음 |
| `kind` `found` | (유치원) `단설`·`병설`·`사립` / 설립 주체 |
| `closed` | (유치원) 휴원 |
| `lv` | (특수학교) 과정별 학급수 `{"초":9,"중":6,…}` |
| `approx` | 좌표 추정 (점선 마커 + `좌표 추정` 표시) |
| `ox` `oy` | 라벨 수동 오프셋(px). 겹치면 자동으로 비켜남 (`lock:true` 면 고정) |
| `dir` | 선호 방향 힌트 `r l t b tr tl br bl` |

새 좌표가 필요하면 [openstreetmap.org](https://www.openstreetmap.org) 에서 해당 위치를
우클릭 → "이 위치 보기" 하면 위도·경도가 나옵니다.

원본 순창 지도의 `ox/oy` 25건과 남원 지도의 8방향 배치 39건은 그대로 계승했습니다.

## 배경지도

화면 오른쪽 위 **배경** 선택창에서 바꿉니다. 고른 값은 그 브라우저에 저장됩니다.

| 값 | 배경 |
|---|---|
| `plain` | 단순 (연회색) — **기본** |
| `soft` | 아주 연하게 |
| `osm` | 원색 (지명 잘 보임) |
| `none` | 배경 없음 — 흰 바탕에 경계와 마커만 |

**타일 제공자는 `tile.openstreetmap.org` 하나뿐이고 키가 필요 없습니다.**
"단순"과 "아주 연하게"는 다른 제공자가 아니라, 같은 타일에 CSS 필터를 걸어
회색으로 눌러 놓은 것입니다(`assets/css/app.css` 의 `.jb-tiles-plain` / `.jb-tiles-soft`).
그래서 제공자 정책이 바뀌어도 배경이 깨지지 않습니다. 톤이 마음에 안 들면
`grayscale` `contrast` `brightness` `opacity` 값만 만지면 됩니다.

> **CARTO 를 쓰지 않는 이유** — 예전에는 CARTO Positron 을 기본으로 썼는데,
> CARTO 가 키를 요구하도록 바뀌면서 타일에 `API KEY REQUIRED` 워터마크가 찍혀
> 나옵니다. 오류가 아니라 **정상 응답(200)** 으로 워터마크 이미지를 주기 때문에
> 앱이 자동으로 알아챌 수 없습니다. 그래서 아예 뺐습니다.
>
> OSM 공식 타일도 [사용 정책](https://operations.osmfoundation.org/policies/tiles/)상
> 트래픽이 큰 서비스에는 맞지 않습니다. 방문자가 크게 늘면 MapTiler·Stadia 처럼
> 키를 발급받는 제공자로 옮기세요. `config.js` 의 `JB.TILE_PRESETS` 에 항목을
> 하나 더하면 됩니다.
>
> ```js
> JB.TILE_PRESETS.mine = {
>   label: '내 타일',
>   url: 'https://.../{z}/{x}/{y}.png?key=발급키',
>   attribution: '&copy; 제공자', maxZoom: 20, cls: ''
> };
> JB.TILE_DEFAULT = 'mine';
> ```
>
> 국내 지명이 촘촘한 배경이 필요하면 VWorld 도 같은 방식으로 붙습니다.

타일을 아예 못 받으면(제공자 장애·연결 끊김) 앱이 알림을 띄우고 `osm` 으로 넘깁니다.
다만 위 CARTO 사례처럼 **정상 응답에 워터마크만 찍혀 오는 경우는 감지하지 못합니다.**

## 배포

빌드 과정이 없는 정적 파일입니다. 폴더째 올리면 끝입니다.

**GitHub Pages** — 저장소가 public 이어야 합니다(private 은 유료 플랜).
Settings → Pages → Source `Deploy from a branch`, Branch `main` / `/ (root)` → Save.
Jekyll 처리를 끄려고 `.nojekyll` 을 넣어 뒀습니다.

**로컬에서 보기** — 폴더 구조를 그대로 두고 `index.html` 을 더블클릭하면 됩니다.
브라우저가 로컬 파일을 막으면 폴더에서 `python -m http.server 8000` 을 띄우고
`http://localhost:8000` 으로 여세요.
