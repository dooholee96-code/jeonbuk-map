# 전북 농촌유학·학교 통합지도

전북특별자치도 **14개 시군 742개 초·중·고**와 **2026학년도 1학기 농촌유학 운영·희망학교**를
한 지도에서 봅니다. 기본 화면은 전북 전체이고, 선택창에서 시·군을 고르면 그 지역만 봅니다.
빌드 도구 없이 `index.html` 을 열면 바로 뜹니다.

```
├── index.html                  앱 셸 (지역·형태 선택 · 검색 · 카드목록 · 지도)
├── assets/
│   ├── css/app.css
│   ├── js/
│   │   ├── config.js           14개 시군 정의, 학교급·농촌유학 분류    
│   │   ├── labels.js           라벨 자동배치 엔진 (겹침 회피 + 지시선)
│   │   ├── geocode.js          좌표 보정 · 경계검증 · 내보내기
│   │   └── app.js              메인
│   └── data/
│       ├── boundaries.js       14개 시군 경계 (로컬 16KB, 외부 요청 없음)
│       └── eupmyeon.js         읍·면·동 중심 좌표
└── data/regions/               ★ 시군별 학교 데이터 — 여기만 고치면 됩니다
    └── jeongju.js  gunsan.js  iksan.js  jeongeup.js  namwon.js  gimje.js
        wanju.js  jinan.js  muju.js  jangsu.js  imsil.js  sunchang.js
        gochang.js  buan.js
```

## 화면

- **지역 선택창** — 기본 `= 전북 전체 (742교) =`, 시부/군부로 묶인 14개 시군
- **형태 선택창** — 초/중/고, 농촌유학 운영, 희망, 운영＋희망
- **검색** — 학교명·읍면동·주소
- **총 N교 / 학생 N명** — 현재 필터 기준 실시간 집계
- **카드 목록** — 학교급·농촌유학 태그, 주소, 전화, 학생수·학급수. 클릭하면 지도가 이동합니다.
  전북 전체에서는 시군별로, 시군을 고르면 읍·면·동별로 묶입니다.
- **라벨** — 기본 `자동`. 전북 전체에서는 농촌유학 학교만, 시군을 고르면 전부 표시합니다.
  줌·이동할 때마다 겹치지 않는 자리를 다시 계산하고, 자리가 없으면 라벨만 숨깁니다(확대하면 다시 나옵니다).

### 출처와 가공 규칙

| 항목 | 출처 | 처리 |
|---|---|---|
| 학교명·소재지·주소·전화·학급수·학생수 | `2026 초중고.xlsx` (초/중/고 시트) | 소계·합계 행 제외, 14개 시군만. 학생수는 특수학급 포함 **합계 전체** 열 |
| 위도·경도 | `2026 초중고 위도경도.xlsx` (744행) | 학교명을 정규화(`초등학교→초` 등)해 매칭. 표시 이름은 이 파일의 정식명칭 사용 |
| 농촌유학 | `희망학교운영학교 2022~.xlsx` | **N열(2026-1학기 희망) · O열(2026-1학기 운영)** 을 읽어, 두 곳에 다 있으면 **운영**, 희망에만 있으면 **희망** |

농촌유학 판별 결과: 희망 59교 ∩ 운영 44교 = 43교 중복 → **운영 44 / 희망 16**.
2026학년도 2학기 희망 신청(P열)에 올라 있는 학교는 `hope2: true` 로 따로 표시해 뒀습니다.

교차검증: 손으로 만드셨던 순창 지도(운영 11 · 희망 2), 남원 지도(운영 2 · 희망 1)와 정확히 일치합니다.

### 남은 6곳

좌표 파일에 없는 신설교입니다. 행정동 중심점을 임시로 넣고 `approx: true` 로 점선 표시했습니다.

전주 양현초 · 온빛초 · 자연초 · 화정초 · 효천초, 익산 궁동초

앱에서 해당 시군을 고르고 **[좌표 보정]** 을 누르면 카카오 장소검색으로 맞춰지고,
**[데이터 내보내기]** 로 확정 파일을 받습니다. 검색이 막히면 상세카드의 **[지도에서 위치 지정]** 으로
직접 클릭해 찍어도 됩니다.

## 데이터 고치기

`data/regions/<시군>.js` 한 파일만 고치면 됩니다.

```js
{"n":"구림초등학교","t":"elem","ph":"구림면","rural":"운영",
 "lat":35.4527504,"lng":127.1009503,
 "addr":"순창군 구림면 방화로 6","tel":"063-652-8434","stu":19,"cls":6}
```

| 필드 | 뜻 |
|---|---|
| `n` `t` | 학교명 / `elem`·`mid`·`high` (필수) |
| `ph` | 읍·면·동 — 목록 그룹 기준 |
| `rural` | `'운영'` \| `'희망'` — 없으면 일반 학교 |
| `lat` `lng` | 좌표 (필수) |
| `stu` `cls` | 학생수 / 학급수 |
| `addr` `tel` | 주소 / 전화 |
| `hope2` | 2026 2학기 희망 신청 |
| `branch` | 분교 |
| `approx` | 좌표 미확정 (점선 마커 + 경고) |
| `ox` `oy` | 라벨 수동 오프셋(px). 겹치면 자동으로 비켜남 (`lock:true` 면 고정) |
| `dir` | 선호 방향 힌트 `r l t b tr tl br bl` |

원본 순창 지도의 `ox/oy` 25건과 남원 지도의 8방향 배치 39건은 그대로 계승했습니다.

## 카카오 앱 키

`assets/js/config.js` 의 `JB.KAKAO_KEY`. 지도 표시는 대부분 환경에서 되지만,
**장소검색(좌표 보정)** 은 [카카오 개발자센터](https://developers.kakao.com) →
내 애플리케이션 → 플랫폼 → Web 에 배포 도메인(및 `http://localhost:포트`)을 등록해야 동작합니다.

## 경계 데이터

[southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps) `kostat/2018` 시군구 경계에서
전북 14개 시군만 뽑아 Douglas–Peucker(≈120m)로 단순화한 뒤 폴리라인으로 인코딩했습니다(18MB → 16KB).
MultiPolygon을 전부 처리해 군산·부안의 섬도 나옵니다. 전주시는 완산구·덕진구를 합쳐 한 항목으로 넣었습니다.
